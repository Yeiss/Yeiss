## What I build

🛩️ &nbsp; **Drone & FPV platforms** — custom add-ons, mounts, mechanical interfaces, professional equipment integration

🤖 &nbsp; **Robotics & embedded prototypes** — electronics integration, C++/Python firmware, assembly, validation

🏗️ &nbsp; **Rapid prototyping** — FDM · SLA · SLS · CNC · laser · waterjet · carbon fiber

🔍 &nbsp; **Reverse engineering** — mechanical interfaces, binary analysis, custom tooling from SDKs

👁️ &nbsp; **Computer vision** — YOLOv6 detection running on prototype systems
